# Gabriela's AI Assistant

Личен AI чат асистент, изграден с чист HTML, CSS и JavaScript, захранван от OpenRouter API.

---

## Описание

Това е изцяло клиентско уеб приложение, което предоставя интерфейс за разговор с изкуствен интелект. Свързва се с OpenRouter API за генериране на отговори в реално време и включва пълна система за управление на чат сесии с локално съхранение — без никакви фреймуъркове или инструменти за билдване.

---

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- OpenRouter API (модел GPT-4o-mini)
- localStorage за съхранение на данни

---

## Функционалности

- Чат с AI в реално време с анимация на пишеща машина
- Множество именувани сесии — създаване, превключване, преименуване и изтриване
- Временен чат режим без запазване на история
- Автоматично съхранение в localStorage с почистване на стари данни
- Напълно адаптивен дизайн за мобилни, таблет и десктоп
- Хамбургер меню със sidebar и поддръжка на swipe жестове на мобилни устройства
- Достъпност — ARIA атрибути, навигация с клавиатура, капан за фокус

## Бележки по имплементацията

- Цялата логика на приложението е капсулирана в единичен клас `GabrielaAI`
- Сесиите се съхраняват като JSON обект в localStorage под ключа `gabriela_ai_sessions`
- API заявката изпраща последните 10 съобщения от историята за контекст
- Системният промпт персонализира асистента за конкретния потребител
- Временните сесии съществуват само в паметта и се губят при затваряне на страницата
